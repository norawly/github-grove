Grove puts your full GitHub contribution calendar in a quiet native desktop card, with a muted username, UTC streak, light/dark appearance, adjustable size, offline cache, and optional pixel sprout.

Download the universal DMG or ZIP for macOS 13+. Move Grove to Applications, open it, enter your GitHub username and save. No terminal, separate account, token, Dock icon or menu-bar icon.

This is an initial preview. It is ad-hoc signed, not Apple-notarized; first launch may require Privacy & Security → Open Anyway. Automated and headless checks are recorded in the repository. Interactive desktop behavior, login items and real resource measurements are pending a dedicated desktop session. Intel support is cross-compiled, not verified on an Intel device.
